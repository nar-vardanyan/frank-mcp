# MCP servers for user research, compared (Nov 2026)

This page is a dated comparison of public MCP servers from 11 user-research products. It was checked on 20 November 2026. Each cell comes from that vendor's own page, or from the server's published OAuth metadata when a docs page did not say whether dynamic client registration (DCR) or Client ID Metadata Documents (CIMD) is supported.

If a page did not state a fact, the cell says **not documented** and names the page. If two pages from the same vendor disagreed, both are quoted. Nothing here is a ranking, and a vendor's marketing sentence is labeled as that vendor's claim.

The versioned dataset is [research-mcp-index.csv](https://github.com/nar-vardanyan/frank-mcp/blob/main/data/research-mcp-index.csv) and [research-mcp-index.json](https://github.com/nar-vardanyan/frank-mcp/blob/main/data/research-mcp-index.json). The tables below are the same cells.

## How we checked

**Last verified 2026-11-20.**

**Method.** For each vendor we opened the public docs, help, pricing, or announcement page that describes the MCP, then the pricing or plan page, then any page that states interview mode or language claims. Where those pages did not say whether DCR or CIMD is supported, we also opened the server's OAuth authorization-server or protected-resource metadata and recorded a field only when it was present. We did not fill a cell from a third-party roundup or from memory.

A cell says **not documented** when the pages we opened did not state that fact. A negative that the vendor does state, such as Maze MCP being on Enterprise, is written as that statement, with the page. Where two of a vendor's pages disagree, the cell quotes both and does not pick one.

Frank's row uses the [frank-mcp README](https://github.com/nar-vardanyan/frank-mcp/blob/main/README.md) and live hifrank.ai pages. The Free plan's 225 signup credits plus 60 voice minutes a month, and Starter at $49 per month when billed yearly, are from the pricing page opened the same day.

**Monthly re-check.** Re-open every source URL on or about the 20th of each month. Change any cell whose page changed, keep the old wording in the changelog, and set the cell's check date to the new day. The next check is 20 December 2026.
