1. Mom Test question checker

Visitors paste their interview questions, one per line. Each question is checked for wording that tends to get polite guesses instead of facts (pitching, compliment seeking, hypothetical price, future or would-you, hypothetical, leading, yes/no), with a short reason and a rewrite. Where to paste

  • Webflow: add an Embed element (Add panel, Components, Embed), paste the script tag, Save and Close, then publish. Embeds do not run in the Designer canvas, so check the published or preview site.
  • WordPress: add a Custom HTML block and paste the script tag.
  • Ghost: add an HTML card and paste the script tag.
  • Blogger: Layout, Add a Gadget, HTML/JavaScript, paste the script tag. In a post, switch to HTML view first.
  • Notion: Notion does not run pasted scripts. Type /embed, choose Embed and paste the Notion URL.
  • Other builders that strip scripts: use the iframe. Raise its height if you see an inner scrollbar on phones.

Optional script attributes: data-frank-theme="dark" or "auto" (Mom Test checker and guide generator), data-frank-blurb="off" hides the one-line description above the credit, and data-frank-goal / data-frank-type preset the guide generator.

"The Mom Test" is a book by Rob Fitzpatrick. The checker's rules are our own heuristics, and the tools are not affiliated with or endorsed by the author.
