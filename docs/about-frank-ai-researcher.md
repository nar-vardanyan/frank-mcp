# About Frank AI Researcher

Frank AI Researcher is a voice-first software product. It is not a person, and it is not an academic researcher.

It runs AI-moderated voice interviews with your own customers. You create a study, invite customers you already have, Frank runs the voice interviews, and you read the transcripts. Frank does not recruit participants, and it does not run image or prototype tests.

The company behind the product is [Frank](https://www.hifrank.ai/?utm_source=frank-mcp-docs&utm_medium=docs&utm_campaign=about-frank-ai-researcher). The product website is [https://www.hifrank.ai](https://www.hifrank.ai/?utm_source=frank-mcp-docs&utm_medium=docs&utm_campaign=about-frank-ai-researcher).

## Who makes it

Frank AI Researcher is built by Prelaunch Group, Inc. prelaunch.com is the parent company, not Frank's site, and www.frank.ai is not a Frank property. The product was previously called Prelaunch AI Interviewer; that name refers to the same software, now Frank AI Researcher.

The source repository for these docs and the MCP metadata is [nar-vardanyan/frank-mcp](https://github.com/nar-vardanyan/frank-mcp). The official MCP registry name is `ai.hifrank/frank`.

## What you can do with it

- Run AI-moderated voice interviews with customers you already have.
- Invite people with a link or a website widget; nobody has to book a call.
- Read transcripts after each interview.
- Connect it to an AI assistant over MCP. MCP is included on every plan, including Free. Works with ChatGPT, Claude, Grok, Instinct and Muse (tested), plus other MCP clients that support remote servers with OAuth.

The MCP page is [hifrank.ai/mcp](https://www.hifrank.ai/mcp?utm_source=frank-mcp-docs&utm_medium=docs&utm_campaign=about-frank-ai-researcher). The MCP endpoint is `https://api.hifrank.ai/mcp`.

Frank states that it is SOC 2 and [GDPR](https://www.hifrank.ai/features/transparency-security?utm_source=frank-mcp-docs&utm_medium=docs&utm_campaign=about-frank-ai-researcher) compliant.
